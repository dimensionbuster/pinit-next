# PinIt 📌

**PinIt**은 그림을 화면 맨 위에 **딱 붙여 두는** 작은 프로그램이에요.
다른 창을 열어도 그림이 안 가려져요. 그림 보면서 공부하고, 게임하고, 그림 그릴 수 있어요! (Windows 전용)

## 1. 프로그램 받기 📥

[Releases 페이지](https://github.com/dimensionbuster/pinit-next/releases)에 가서 **둘 중 하나**만 받으면 돼요.

- **설치 버전** — 이름이 `PinIt-v숫자-windows-setup.exe` 인 파일
  1. 받은 파일을 두 번 눌러요.
  2. 시키는 대로 "다음"을 눌러요.
  3. 시작 메뉴에서 **PinIt**을 찾아 눌러요.
- **포터블 버전** — 이름이 `PinIt-v숫자-windows-portable.zip` 인 파일
  1. 받은 파일을 눌러 **압축을 풀어요.**
  2. 안에 있는 `PinIt.exe`를 두 번 눌러요.
  3. 설치가 없어요. USB에 넣어 다녀도 돼요!

> 윈도우 10이라면 **Microsoft Edge WebView2 Runtime**이 필요할 수 있어요. 안 켜지면 이름을 검색해서 설치해 주세요.

## 2. 그림 붙이기 🖼️

PinIt을 켜면 **설정 창**이 나와요. 그림을 **설정 창 위로 쓱 끌어다 놓으면** 끝이에요! 🎉

- **내 컴퓨터 그림** — 폴더에서 그림 파일을 끌어다 놓아요.
- **웹 그림** — 인터넷 페이지의 그림을 그대로 끌어다 놓아요.

그림이 작은 창으로 짠! 하고 떠요. 이 창은 **항상 맨 위**에 있어요.
(우클릭으로 붙이는 방법은 아래 4번에 있어요.)

## 3. 그림 마음대로 만지기 ✋

그림 창 위에 마우스를 올리면 아래에 버튼이 나와요. 키보드와 마우스로도 할 수 있어요.

| 하고 싶은 것 | 이렇게 해요 |
|---|---|
| 창 옮기기 | 그림을 **왼쪽 버튼으로 끌어요** |
| 크게 / 작게 보기 | 마우스 **휠**을 굴려요 |
| 그림 밀어서 움직이기 | `Space`를 누른 채 끌어요 (또는 휠 버튼으로 끌어요) |
| 빙글 돌리기 | `R` (시계 방향) / `Shift`+`R` (반대로) |
| 살짝 기울이기 | `Alt` + 휠 |
| 거울처럼 뒤집기 | `H` (좌우) / `V` (위아래) |
| 처음처럼 되돌리기 | 그림을 **두 번 빠르게 눌러요** (또는 `0`) |
| 창 크기 바꾸기 | 창 가장자리를 끌어요 |
| 창 닫기 | 오른쪽 위 **닫기 버튼** |

## 4. 웹에서 바로 붙이기 (브라우저 확장) 🌐

인터넷 그림을 **우클릭 한 번**으로 붙일 수 있어요! 처음에 딱 한 번만 준비하면 돼요. (크롬 같은 Chrome 계열 브라우저용이에요)

1. PinIt 설정 창에서 **브라우저** 칸을 찾아 **확장 폴더 열기**를 눌러요.
2. 브라우저 주소창에 `chrome://extensions` 를 쳐요.
3. 오른쪽 위 **개발자 모드**를 켜요.
4. **압축해제된 확장 프로그램을 로드**를 누르고, 1번에서 열린 폴더를 골라요.

이제 웹에서 아무 그림이나 **우클릭 → "PinIt으로 열기"** 를 눌러 보세요. 그림이 짠! 🎉
설정 창에 "연결됨"이라고 나오면 성공이에요.

> 브라우저를 켤 때 "개발자 모드 확장" 경고가 떠도 괜찮아요. 걱정 마세요!

## 5. 여러 그림 정리하기 🧹

- **다시 정렬** — 흩어진 그림 창들을 예쁘게 줄 세워 줘요.
- **모두 닫기** — 그림 창을 한꺼번에 닫아요.
- **저장 / 불러오기** — 지금 모습을 `.pinit` 파일로 저장해 두고 나중에 다시 불러올 수 있어요.
- **색깔 바꾸기** — 그림 뒤 배경 색, 투명한 정도, 밝은/어두운 테마를 고를 수 있어요.

## 6. 끄기와 숨기기 🌙

설정 창을 닫아도 PinIt은 **작업 표시줄 오른쪽 아래(트레이)** 에 숨어 있어요. 거기서 다시 열 수 있어요.
완전히 끄려면 설정 창의 **종료** 버튼을 눌러요.

## 7. 업데이트 🔔

새 버전이 나오면 설정 창 맨 위에 알림이 떠요. 알림만 뜨고 저절로 바뀌진 않아요. [Releases 페이지](https://github.com/dimensionbuster/pinit-next/releases)에서 새 버전을 다시 받아 주세요.

## 개발

```
npm ci
npm run dev:app        # 개발 실행
npm run check          # tsc + 테스트
npm run build:portable # release-portable/PinIt 생성
npx tauri build --bundles nsis # 설치 파일
```

자세한 내용은 [docs/DEVELOPING.md](docs/DEVELOPING.md).

## 릴리스 절차

1. `npm version x.y.z` (또는 `patch`/`minor`/`major`) — package.json, Cargo.toml, tauri.conf.json, Cargo.lock 버전을 한 번에 갱신하고 `x.y.z` 커밋 + `vx.y.z` 태그 생성
2. PR → `main` 머지 (merge commit, squash 금지)
3. `Release` 워크플로가 `vx.y.z` **초안(draft)** 릴리스와 포터블 zip과 설치 파일(NSIS)을 자동 생성 (같은 버전의 릴리스가 이미 있으면 건너뜀)
4. 초안의 노트를 다듬고 **Publish** — 공개되는 순간부터 실행 중인 앱이 업데이트 알림을 표시
